# Entire — facts sheet

Sources: https://entire.io (homepage, read 2026-10-11); https://github.com/entireio/cli. Only facts stated there.

## What it is
- Tagline: "Every agent session stored in your repo."
- Git hosting platform and CLI that stores each agent session, prompt and tool call alongside your commits.
- Founded by former GitHub CEO Thomas Dohmke (launched February 2026).

## Features
- A checkpoint for every commit, linking the code change to the agent session that produced it.
- Sessions sync with commits: conversations are captured and linked to git history automatically.
- Private by design: secrets are detected and redacted before anything is stored.
- Send a branch to multiple agents in parallel for review.
- Search both code changes and the sessions that explain them.
- Resume work across agents with session state carried forward.
- Host code in-region: India, Australia, EU and US.
- One command creates a regional mirror of a GitHub repo.
- Works with Claude Code, Codex, Gemini, Cursor, GitHub Copilot, Pi, OpenCode, Droid, Antigravity and Amp.
- The CLI is open source (MIT licensed).

## Pricing
- No prices are published on the homepage. The CLI is free and open source.
