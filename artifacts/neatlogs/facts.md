# neatlogs — facts sheet

Source: https://neatlogs.com (homepage and pricing, read 2026-10-11). Only facts stated there.

## What it is
- Tagline: "The fastest path from failure to fix."
- neatlogs finds what's failing in AI agent runs, works out why, and hands you a fix.
- Built for teams shipping agents.

## Features
- Traces & Detections: see every production run and the failures hiding inside them.
- Investigations: evidence, root cause, and a fix brief a coding agent can ship.
- Evals: describe what good looks like and score every run against it.
- Collaboration: support, product and engineering work from the same evidence.
- Ask @neatlogs questions in Slack, the app, or Linear.
- Investigate from the terminal via the CLI or MCP.
- SDKs for Python, TypeScript and Go.

## Pricing
- Free: $0 forever — 100k spans/month, 3 investigations/month, 5 detectors, 2 users, 1 project, 14-day retention.
- Starter: $99/month ($84/month billed annually) — 250k spans/month, 50 investigations/month, unlimited users, 5 projects, 30-day retention.
- Pro: $499/month ($424/month billed annually) — 1M spans/month, unlimited investigations and evaluations, audit log and SSO, 90-day retention.
- Enterprise: custom annual pricing — SAML/SCIM, data residency, VPC or self-hosted ingest, SLA.
- Starter and Pro: first month free.
