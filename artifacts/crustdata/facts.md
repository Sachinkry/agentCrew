# Crustdata — facts sheet

Source: https://crustdata.com (homepage, read 2026-10-11). Only facts stated there.

## What it is
- Real-time B2B data for AI agents: people and company data via API or MCP server.
- Indexes web pages into a live graph of people and companies.
- For sales, recruiting and investing teams, plus developers and platform builders.

## Features
- Search: live search over people and companies.
- Enrich: enrichment of people and company records.
- Watch: watchers that alert on changes (Watcher API).
- Company Search API, Company Enrichment API, People Search API, People Enrichment API.
- Jobs API and Posts API.
- REST API, MCP server and skill templates.
- Data quality focus: freshness (continuous re-verification), depth and identity resolution.
- Use cases: AI SDRs, recruiting platforms, venture capital deal sourcing, customer success tracking.

## Coverage
- The site states 1B+ people. Company counts on the site differ (60M+ in one place, 200M+ in another), so don't quote a company number.

## Pricing
- No prices on the homepage. A free sandbox API key is available for developers.
