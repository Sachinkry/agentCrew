# AI Prompt Pack for Recruiters — 25 Ready-to-Use Prompts

## Job Description Writing

### JD-01: Write a compelling job description
```
Write a job description for [JOB TITLE] at [COMPANY NAME], a [COMPANY TYPE/STAGE] company.
The role involves [3 KEY RESPONSIBILITIES]. Required skills: [SKILLS LIST].
Salary range: [RANGE]. Make it engaging, avoid jargon, and emphasize growth opportunity.
Format: Title, 2-sentence hook, About Us (3 sentences), Responsibilities (5 bullets), Requirements (5 bullets), Nice-to-haves (3 bullets), Benefits (4 bullets).
```

### JD-02: Rewrite a stale job description
```
Rewrite this job description to be more engaging and modern. Remove clichés like "rockstar", "ninja", "self-starter".
Use inclusive language. Keep it under 400 words. Original: [PASTE JD HERE]
```

### JD-03: Create a job description from a LinkedIn profile
```
Create a job description to hire someone like this LinkedIn profile. Infer the key skills and responsibilities.
Add a "Why this role is unique" section. Profile: [PASTE PROFILE]
```

## Candidate Sourcing

### SRC-01: Boolean search string generator
```
Create a LinkedIn Boolean search string to find candidates for [JOB TITLE] with [REQUIRED SKILLS].
Include synonyms and exclude [INDUSTRIES TO EXCLUDE]. Format: ready to paste into LinkedIn Recruiter.
```

### SRC-02: Outreach message — cold (first touch)
```
Write a personalized cold outreach message to [CANDIDATE NAME] for a [JOB TITLE] role at [COMPANY].
Reference their work at [CURRENT COMPANY] and their experience with [SPECIFIC SKILL/PROJECT].
Keep it under 150 words. No generic "I came across your profile" openers.
```

### SRC-03: Outreach message — warm (referred by someone)
```
Write a LinkedIn message to [CANDIDATE NAME] mentioning that [REFERRER NAME] suggested we connect.
Role: [JOB TITLE]. Keep it conversational and under 100 words.
```

### SRC-04: Follow-up sequence (3 messages)
```
Write a 3-message follow-up sequence for a candidate who hasn't responded to my initial outreach.
Initial message was about [JOB TITLE] at [COMPANY]. Tone: professional but human. 
Message 1 (3 days after): gentle nudge
Message 2 (7 days after): add value (share something interesting about role/company)
Message 3 (14 days after): closing "just checking in" 
```

## Screening & Interviewing

### INT-01: Screening call questions
```
Generate 8 screening call questions for [JOB TITLE]. 
Include: 2 culture-fit questions, 2 role-specific technical questions, 2 situational questions, 2 motivation questions.
For each, include what a strong answer looks like.
```

### INT-02: Structured interview scorecard
```
Create a structured interview scorecard for [JOB TITLE]. 
Include 5 competencies, each with 3 behavioral questions and a 1-5 rating rubric.
Format as a table I can share with the hiring panel.
```

### INT-03: Technical assessment brief
```
Write a take-home technical assessment for [ROLE] that can be completed in 2 hours.
Include: context (realistic scenario), task description, evaluation criteria, submission instructions.
Make it respectful of candidate time and relevant to day-to-day work.
```

### INT-04: Debrief facilitation script
```
Write a structured debrief script for a hiring panel of [N] people after interviewing candidates for [JOB TITLE].
Include: how to share notes without groupthink, scoring aggregation, red flag discussion, decision framework.
Time-box: 30 minutes.
```

## Offer & Closing

### OFR-01: Verbal offer script
```
Write a verbal offer call script for [CANDIDATE NAME] for the [JOB TITLE] role.
Offer details: Salary [AMOUNT], Equity [AMOUNT/TYPE], Start date [DATE], Benefits highlights [LIST].
Include: enthusiastic opener, offer summary, space for questions, next steps.
```

### OFR-02: Offer letter email
```
Write a formal offer letter email for [CANDIDATE NAME].
Company: [COMPANY]. Role: [TITLE]. Start: [DATE]. Salary: [AMOUNT]. Reports to: [MANAGER].
Professional but warm. Include what documents they'll need and who to contact with questions.
```

### OFR-03: Counter-offer response
```
[CANDIDATE NAME] has received a counter-offer from their current employer of [AMOUNT] more than our offer.
Our max budget is [AMOUNT]. Write a response that emphasizes non-monetary value (growth, culture, impact)
and makes a case for our offer without just competing on salary. Keep it under 200 words.
```

## Rejection & Candidate Experience

### REJ-01: Rejection email (post-screen)
```
Write a respectful rejection email to [CANDIDATE NAME] who applied for [JOB TITLE].
They made it through [SCREENING STAGE]. Reason (keep vague): [REASON].
Tone: warm, no corporate template feel. Offer to keep them in mind for future roles.
```

### REJ-02: Rejection email with feedback
```
Write a rejection email to [CANDIDATE NAME] for [JOB TITLE] that includes constructive feedback.
They interviewed well but [SPECIFIC REASON]. Keep feedback specific but kind.
Offer 1 suggestion for their job search.
```

## Employer Branding

### EB-01: LinkedIn company page post
```
Write a LinkedIn post for [COMPANY]'s page celebrating [EMPLOYEE NAME/TEAM] who just [ACHIEVEMENT].
Include: what they did, why it matters, 1 quote from them (fictional, you generate), CTA to follow the page.
Hashtags: 3-4 relevant. Keep under 200 words.
```

### EB-02: "Life at [Company]" Instagram caption
```
Write an Instagram caption for a photo of [DESCRIBE PHOTO - e.g., team offsite, office, virtual event].
Company: [COMPANY]. Culture values: [VALUES LIST]. Keep it authentic, not corporate.
Under 150 words. Include 5 hashtags.
```

### EB-03: Glassdoor response to negative review
```
A former employee left this Glassdoor review: [PASTE REVIEW].
Write a professional, non-defensive response from a [TITLE] at [COMPANY].
Acknowledge the feedback, explain what has changed (if applicable), thank them.
Under 150 words.
```

## Metrics & Reporting

### RPT-01: Weekly recruiting summary
```
Turn these recruiting metrics into a 1-page summary for the leadership team:
[PASTE YOUR DATA - open reqs, pipeline by stage, offer acceptance rate, time-to-fill, etc.]
Format: executive summary (3 bullets), metrics table, top 3 actions needed.
Make it skimmable in 2 minutes.
```

### RPT-02: Hiring manager update
```
Write a quick update to hiring manager [NAME] on the search for [JOB TITLE].
Current status: [PIPELINE STATUS]. Recent actions: [WHAT YOU'VE DONE]. Blockers: [IF ANY].
Next steps: [NEXT ACTIONS]. Keep it under 150 words, bullet-point format.
```

## Negotiation & Difficult Conversations

### DIF-01: Handle a candidate who's ghosting
```
Write a final outreach message to a candidate who went silent after [STAGE] in the process.
Role: [JOB TITLE]. Last contact: [TIMEFRAME]. Tone: friendly, no guilt-tripping.
Give them an easy out if they're no longer interested.
```

### DIF-02: Rescind an offer gracefully
```
We need to rescind an offer to [CANDIDATE NAME] due to [REASON - e.g., budget freeze, role eliminated].
They haven't started yet. Write a professional, empathetic phone call script and follow-up email.
Offer any support you can (referral, LinkedIn recommendation, future consideration).
```
